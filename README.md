# 🦖 Dino Game

A clone of the famous Google Chrome dinosaur game, developed in **C++** using the **Raylib** library. This project focuses on recreating the classic core mechanics, including running, obstacle avoidance, and progressive score tracking.

---

## 🚀 Features
*   **Classic Mechanics:** Jump and duck to avoid incoming obstacles.
*   **Progressive Difficulty:** The game speed increases as your score grows.
*   **Clean Interface:** Simple 2D graphics rendered in real-time via Raylib.
*   **Cross-Platform Support:** Configured with CMake for straightforward compilation on Linux and Windows.

---

## 🛠️ Prerequisites (Linux / Ubuntu)
Before building the project, ensure you have the following packages installed on your system:

```bash
# Update system packages
sudo apt update

# Install C++ compiler and CMake
sudo apt install build-essential cmake

# Install the Raylib library
sudo apt install libraylib-dev
```

---

## ⚙️ How to Build and Run

Follow these steps in your terminal to clone, compile, and run the game:

### 1. Clone the repository
```bash
git clone https://github.com/goncas200/dinogame.git
cd dinogame
```

### 2. Generate build files with CMake
```bash
cmake -B build -DCMAKE_BUILD_TYPE=Debug
```

### 3. Compile the project
```bash
cmake --build build -j $(nproc)
```

### 4. Run the game
```bash
./build/dinogame
```

---

## 🎮 Controls
*   **[SPACE] / [UP ARROW]:** Jump over obstacles.
*   **[R]:** Restart the game after Game Over.
*   **[ESC]:** Exit the game.
